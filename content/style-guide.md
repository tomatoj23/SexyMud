# 文风指南（叙事内容硬约束）

所有叙事字段（怪物/装备/武功描述、奇遇事件、combat-text 模板与词库、lore 长文）必须遵守本指南。Schema 校验管格式，本指南管语体——两者都是硬门禁。

**作用域声明**：本指南的禁止词与规范约束的是**叙事内容**（上列字段）；文档自身的说明性文字（设计文档论述、本指南的说明句等）不受禁止词约束，但应尽量减少使用。例：「玩家」禁止出现在叙事文本中，本指南的说明句可用。

## 总纲

- **语体**：古典白话武侠（金庸式叙事为基准，古龙式短句可选作风味变体），不是网文爽文体，不是修仙文，不是西幻。
- **视角**：第三人称或对玩家的第二人称"你"，同一集合内保持一致。
- **长度**：单条描述 1~3 句；奇遇事件 3~6 句；lore 长文不限但须成段成章。

## 用词规范

**必须使用**（与 `CONTEXT.md` 术语一致）：
- 造诣档位：不堪一击 / 初窥门径 / 驾轻就熟 / 炉火纯青 / 出神入化 / 返璞归真（完整 50 档见 `docs/research/xkx100-kungfu-combat.md` §5.1，**档位名不得杜撰**）
- 武功分**招式**与**心法**，品阶称**下乘 / 中乘 / 上乘 / 绝学**
- 学习武功的道具称**秘籍**；配方称**丹方**；配方解锁、**门派贡献**兑换
- 装备稀有度称**寻常 / 精良 / 罕见 / 绝世**；战斗场景称**秘境**（分**层**）
- 离线结算的叙事称**静修**（"静修有期限"表上限）；注意与**在线的练功**区分（`CONTEXT.md` 离线结算 / 练功词条）

**禁止出现**：
- 现代词汇：系统、面板、玩家、经验值、金币、副本、boss、 buff、技能点、充值、VIP
- 修仙词：金丹期、元婴、灵气、渡劫、飞升（题材是武侠不是修仙）。**例外**：造诣 50 档中的「超凡入圣」「天人合一」经定案**豁免**，不适用本条（完整列表见 `docs/research/xkx100-kungfu-combat.md` §5.1）
- 西幻词：法师、魔法值、公会、精灵、符箓
- 数值直出的干瘪句："造成 100 点伤害"（应写"受创 100 点"类描写，数值由模板槽位填入）

**敏感边界**：不出现真实历史人物姓名与真实朝代年号；江湖门派为架空；不写血腥细节（"筋断骨折"可，肢体残缺描写不可）；不涉政治。

## combat-text 模板规范

- 槽位共 13 个，**一律平等**（schema 不分两类）：填空变量 9（`{attacker}` `{defender}` `{move}` `{weapon}` `{defenderWeapon}` `{limb}` `{damage}` `{consequence}` `{elementFlavor}`）+ 修饰片段 4（`{opening}` `{moveIntro}` `{weaponAction}` `{verb}`），分组仅为理解方便。变量名与 `docs/agents/content.md` 的约定一致
- 后果词库分池依据 = **伤害档（轻/中/重/濒死）× 剩余生命档（满/多/半/少/危）× 作用方式（内功/外功）× motion（thrust/sweep/chop/grapple）× 系别**，档内词条风格一致；细则以 `content.md` 维度表为准
- **品阶只渗透修饰性词库与片段数，主干词库（后果/动词/部位）不分品阶**：
  - 片段数：下乘 3 段／中乘 4 段／上乘 5-6 段／绝学 7 段
  - 修饰性词库（`{opening}` 起势 / `{moveIntro}` 招式引出 / `{weaponAction}` 兵器动作）按品阶分池：下乘平实、中乘带情绪、上乘带身法意象、绝学专属意象
  - 绝学 = 2-3 句华丽长句，可带「起势蓄力 → 出手 → 余韵」跨句结构
- 门控三条，四档一视同仁：① 致命部位仅当 伤害档 ∈ {重, 濒死} 且 剩余生命档 ∈ {少, 危}；② 兵器类型决定动词池（剑→刺/点/撩/抹/扫/劈，刀→劈/砍/斩/削，棍→扫/砸/抡/戳，拳掌→拍/击/推/按）；③ 先定节奏档（急/缓/稳），各片段只从同档抽
- 暴击 / 闪避 / 反伤 / 中毒 各有专属模板池
- 招式名出现时用「」括起：「白虹贯日」

## 示例（风格基准）

> 你使出一招「白虹贯日」，剑尖直取黑衣人咽喉！黑衣人侧身急闪，剑风扫落一缕鬓发，堪堪避过。

> 你渊渟岳峙，气机早已锁定黑衣人周身要害——一招「白虹贯日」倏然施出，剑光如龙，盘旋三匝，长剑刺向黑衣人后心，伤口边缘瞬间烙成黑褐色。剑光散尽，黑衣人拄剑半跪，鲜血自嘴角蜿蜒而下。

> 这柄"流云剑"乃百炼精钢所铸，剑身隐有云纹流转。剑鞘是江南水牛皮所制，虽非名贵，胜在趁手。

> 你在后山采得一支七叶灵芝，根须犹带山岚湿气。老药师眯眼端详半晌："成色上佳，够炼一炉小还丹了。"

## agent 批量生产守则

1. 先读本指南与目标集合的既有条目，对齐语体再动笔
2. 同一批次产出的文本避免句式雷同（连读三段不得使用相同句式开头）
3. 产出后运行 `corepack pnpm content:check`（**不得**用 `npm run`，见 ADR-0007），并自查本指南"禁止出现"清单
