# 任务文本体系·总纲（设计稿）

> **定位**：这是**叙事设计稿与文本生产计划**，不是 schema 提案。所有任务文本暂存于 `docs/quests/`（Markdown），不进 `content/`、不动 `schemas/`、零引擎假设。将来任务体系立项时，回到 ADR-0008 重开 schema 决策，本套文本按定案形态迁移入库。
>
> **术语说明**：「任务」一词暂用（与发起语境一致），`CONTEXT.md` 未收录此词——schema 立项时再定正名（候选：差遣／委托／江湖事），届时补进术语表。

> ⚠️ **MUD 转向后的定位（2026-09-01）**：本文写于放置游戏时期，但**结论仍然成立且更重要**——MUD 转向后本作真的有房间、人物与可承接的目标了（ADR-0016/0021），任务从「放置的附属」升级为「MUD 的主菜」。文中「放置」语境下的表述（挂机、放置节奏）应读作**在线的命令驱动节奏**；分卷依据已由境界段改为造诣档位段（ADR-0019）。

## 一、设计立场：任务不是跑腿，且不能要求循环之外的操作

玩家在修习与行走，任务**不能要求任何现有循环之外的操作**。任务在本作里只做三件事：

1. **进度翻译**——把「练功 4 小时」「乱葬岗推到第 3 层」这类数值进度，翻译成一个江湖故事；
2. **里程碑仪式**——招式解锁、造诣跃升、首通、首炼，用叙事给修习行为赋予「值得」的确认感；
3. **钩子**——下一段文本永远比上一段多透露一点世界，让「玩到下一条」成立。

**全部完成条件只映射现有六系统的可观测量**：练功时长／实战经验进度、秘境层数／击杀数、采集与炼丹、门派贡献、装备稀有度首达。零新交互，零新数值，零引擎改动。

## 二、六卷结构（造诣段 × 玩家旅程 ≈ 100 小时）

> ⚠️ **ADR-0019 后的口径**：原按「境界段」分卷，改为按**造诣档位段**分卷（50 档表见 `docs/research/xkx100-kungfu-combat.md` §5.1）。分卷依据是玩家旅程而非数值门槛，因此改动只影响标注，不影响六卷的叙事设计。

| 卷 | 造诣段 | 玩家旅程 | 目标时长 | 文本气质 |
|---|---|---|---|---|
| 卷一·立足 | 不堪一击 | 小镇求生，打熬筋骨 | ~4h | 市井烟火，小人物恩怨 |
| 卷二·拜山 | 初窥门径 | 拜入门派，师门差遣 | ~10h | 规矩与薪火，三门派文风分化 |
| 卷三·行走 | 驾轻就熟 | 走镖州府，风物人情 | ~18h | 江湖路远，古龙式短句渐入 |
| 卷四·扬名 | 炉火纯青 | 卷入江湖大事 | ~28h | 门派恩怨，正邪相争 |
| 卷五·问鼎 | 出神入化 | 秘宝惊案，群雄逐鹿 | ~25h | 苍凉，得与失 |
| 卷六·传灯 | 返璞归真 | 开宗立派／归隐传艺 | ~15h | 天下第一之后的事 |

（造诣段列是 50 档中的**代表性档位**，非硬门槛——卷的划分依据是玩家旅程。）

卷与卷之间用**收束任务**缝合（如卷一末「出镇的官道」= 造诣升至「初窥门径」的叙事仪式，自然引出卷二拜山），玩家感受到的是连续的江湖生涯，不是关卡切换。

**首尾闭环**：卷一留下的意象（渡口的船、老镖头、官道老槐树、一封荐信）在卷六「传灯」全部回收。本作的长线记忆点靠意象复现，不靠剧情强制。

## 三、五类任务（类型学）

| 类型 | 映射系统 | 文本模式 | 每卷量级 |
|---|---|---|---|
| **境·里程碑** | 练功／实战经验／造诣跃升 | 进度确认的叙事仪式；每造诣段 1 条主仪式 + 6~10 条分段 | 主线骨架 |
| **差遣** | 门派贡献／秘籍／兑换 | 师门事务，带门派气质 | 8~20 条 |
| **悬赏** | 秘境推层／击杀／层主 | 捕快告示、苦主相托、行会委托 | 10~30 条 |
| **营生** | 采集／炼丹 | 铺子订单、药农生计 | 6~15 条 |
| **奇遇** | （随机投放，将来落 `event/`） | 触发—文本—收束，含长线伏笔 | 全局池 120 条 |

**每条任务三段式**（借鉴巫师 3 任务日志，压缩到 MUD 节奏）：

- **接取**（2~4 句）：委托人 + 缘由。委托人必须有名有姓有处境；
- **途中**（1~2 句 × 2~3 变体）：进度中点曝光，写「路上」而非「进度条」；
- **了结**（2~3 句）：收束 + 余味或小反转。允许留一句钩子。

## 四、百小时曝光量论证

- 100h ≈ 6000 分钟；有效文本曝光节奏 ≈ **每 10 分钟一条**（接取／途中／了结均计）→ 全程约 600 次曝光；
- 同一文本**第二次见可接受**（玩家的记忆曲线），第三次进入疲劳区 → 重复率上限 30%；
- 结论：需独立主任务文本 **~425 条**，分布 30／50／80／110／100／55（卷一~卷六；卷六刻意变稀——返璞归真阶段文本变少但变重）；
- 另备**奇遇池 120 条**随机补位（跨卷复用，约补 150 次曝光）；
- 每条主任务平均 150 字（三段合计）、奇遇平均 80 字 → **总文本量 ≈ 8 万字**，分四批生产（见 §八）。

## 六、反仙侠军械库（本体系的红线）

题材定案是武侠。仙侠的世界在云端（仙门、灵石、法器、飞升），武侠的世界在码头（漕运、私盐、镖旗、当票）。**每一条文本，用名词把世界钉在码头这一侧。**

| 禁用（仙侠／网文修真） | 武侠替代 |
|---|---|
| 宗门／仙门 | 门派 |
| 灵石、灵气 | 银两、铜钱、内力 |
| 法宝、法器、灵器 | 兵刃、暗器、名剑 |
| 灵草、灵药、仙丹 | 药材（写实命名：当归、三七、七叶灵芝） |
| 储物袋、乾坤戒 | 褡裢、包袱、木匣 |
| 御剑、遁光 | 骑马、舟车、两条腿 |
| 洞府、秘境（仙家） | 山寨、别院、庄园（**本作「秘境」为系统术语**，叙事中按实体称呼：乱葬岗、黑水寨） |
| 修士、道子 | 江湖客、武人、后生 |
| 飞升、渡劫、大乘 | 无对应——武侠的终点是「宗师」「归隐」「传灯」 |
| 天材地宝 | 神兵、古谱、雪莲（写实可考之物） |

**市井语汇库**（百小时不重样的原料，生产时从库中轮换）：

- **人物**：镖头、趟子手、老把式、捕头、仵作、更夫、货郎、药铺掌柜、当铺朝奉、船娘、脚夫、盐枭、漕帮头目、说书人、私塾先生、面摊老板娘、浆洗婆、游医、相士、赌坊荷官、皮货商、瓷商、马贩子、镖局旧人、抓药的学徒、哑仆、守山猎户；

- **器物**：镖旗、路引、海捕文书、当票、算盘、账本、醒木、水牌、扁担、麻绳、桐油、粗盐、茶砖、瓷瓶、粗布、炊饼、虱子、灯笼、木剑、青竹棒；

> 词汇密度是防重样的第一手段：同一委托人不连用两条，同一场所不连用三段。

## 七、文风军规（在 `content/style-guide.md` 之上的任务文本补充）

1. 统一第二人称「你」；古典白话，金庸基准，卷三起可杂古龙短句；
2. 委托人**有名有姓有处境**，姓从武侠常见姓轮换，名从职业／药材／排行取（孙半夏、赵老刀、三哥、白先生、邓货郎）；
3. 报酬叙事用银两／实物／人情（「一顿鱼」「一拳肩膀」「不收船钱」），**不绑定未定的货币系统**——数值层留给将来 schema 的奖励字段，文本只写「多给了八文钱」；
4. 叙事时长单位约定：小时→时辰，天数→日；伤害、数值一律走槽位不直书；
5. 触发条件是设计说明（本稿以引用块标注），不进叙事文本；
6. 严守 style-guide 禁词表 + 本文 §六红线 + 句式三不同（连读三段不同句式开头）；
7. 敏感边界照旧：架空地名门派、无真实朝代年号、不见血腥细节、不涉政治。
