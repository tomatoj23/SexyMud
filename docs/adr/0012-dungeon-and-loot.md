# 秘境与掉落：定时波次涌现难度 + 可配置掉落链，底材分层且词缀倾向标签化

> ⚠️ **待重估（2026-09-01）**：本文的「层内定时波次」是**放置游戏时期**的模型（自动战斗 + 波次生成）。MUD 转向后秘境是由**房间**构成的空间（ADR-0016），敌人应是**驻守 + 定时刷新**，而非波次推进。
> **已作废的条目**：第 1–2 条的波次公式（随波次模型失效）；**第 7 条「离线推进」整条**（ADR-0016 已定离线不自动战斗、不推层）；**第 14 条「离线掉落」**（依赖离线战斗，Offline 只补气血/内力与基础熟练度，见 ADR-0019）；第 5 条的「推荐境界」已改为 `recommendedPower` 战力区间（ADR-0019）。
> **仍然有效**：掉落 8 步管线、**稀有度是因、词条数是果**、底材分层 + 词缀倾向标签化、特色词缀即机制改变、参数在 config。

秘境层内模型 = **定时波次**（`触发下一波 = 时间到 OR 上一波已清空，取较早者`），**难度是涌现的**（清怪速度 vs 生成速度的比值），不是配出来的；四参数全在 `content/config/`。掉落走 **8 步可配置管线**，**稀有度是因、词条数是果**；掉落**击杀时即时入库**，掉落记录只在当前探索会话内存活。底材**分层**（高层掉的是另一个底材条目，不是同一条目加 `itemLevel`），词缀倾向用**标签**表达而非显式列表。

## Context

秘境是放置游戏的战斗容器：既要支持离线 O(1) 推进（与 ADR-0010 的稳态 DPS 配套），又要让"变强"有可感知的节奏。掉落是构筑玩法的入口（ADR-0005），其管线必须在不碰引擎的前提下可加步骤、可加底材、可加词缀。xkx100 的掉落是硬编码判定，其建议（`unlocks` 显式解锁链 + 境界区间字段）值得吸收（见 `xkx100-kungfu-combat.md` §7 与 BRIEF §8.6）。

## Decision

1. **定时波次**：`进入第 N 层 → t=0 生成第 1 波 → t=T1 或 第1波清空（取先到）生成第 2 波 → … → 场上清空 且 波次已全部生成 → 通关本层`。难度**涌现**于清怪速度与生成速度的比值。
2. **四参数全在 `content/config/`**：`waveCount`（本层几波）／`waveInterval`（波间隔：固定值／区间随机／逐波递减）／`waveComposition`（每波什么怪：固定表／从池随机）／`maxConcurrent`（场上怪物上限，**技术护栏 12–20，非难度调节**；超出延后而非丢弃）。
3. **随机化两层**：间隔 `T ± 20%`；构成本层池随机 + 保底固定；**精英/Boss 不进随机池**。原则：**随机性放在节奏与搭配上，不放在难度上**。
4. **层主**：每 N 层一个（如第 5、10 层），非每层都有；层主带机制 = 用现有 primitive 组合（`content/effects/`），**不新增引擎能力**。
5. **解锁混合式**：前几个秘境链式引导（显式 `unlocks: <下一层 id>` 字段），之后按**推荐战力区间**（`recommendedPower: [min, max]`）并列开放；它是**软提示**，硬门槛只用于"未通关前一层"。显式解锁链与战力区间字段供校验器检查**连通性闭环**与**战力段覆盖**。
6. **层 modifier**：如"此层火系伤害 +30%"，与怪物亲和度**同族，复用同一套**（见 ADR-0009 第 5 条）。
7. ~~**离线推进**~~：**已作废**（ADR-0016：离线不自动战斗、不推层）。
8. **掉落时机 = 击杀时即时入库**（非探索结束统一结算）。击杀瞬间浮动提示；探索结算给汇总列表（按品阶/稀有度排序）。**掉落记录只在当前探索会话内存活**——会话结束展示一次，强退不展示；数据已在背包，**不为掉落日志新增存档字段**。
9. **掉落链是管线，不能写死**：`① 掉不掉 → ② 按秘境层数筛选可用底材池 → ③ 选一个底材 → ④ 掷稀有度 → ⑤ 按稀有度定词缀条数 → ⑥ 抽词缀（受底材偏好标签影响）→ ⑦ 每条词缀掷阶位（受底材声明的品阶范围限制）→ ⑧ 附加底材固有词缀（固定，非随机）`。**稀有度是因，词条数是果**。
10. **底材 = 分层条目**：高层掉的是**另一个底材**（换名字/描述/美术），而非同一条目加 `itemLevel`；每个底材声明**槽位 / 固有词缀 / 偏好标签 / 层数区间 / 品阶范围**。`itemLevel` MVP **不启用**，降级为可选乘数（默认 1.0）。美术侧由 `ADR-0003:8` 的 id 约定路径天然支持一底材一图标。
11. **词缀倾向 = 标签化**：底材只声明 `preferredTags`，词缀自带 `tags`；`权重 = 基础 × (1 + 匹配标签数 × 加成)`，加成 1.0，**多标签温和叠加而非相乘**（避免 ×9 失控）。新增词缀带上 `tags` 即自动被所有偏好该标签的底材青睐（兑现 `ADR-0008:15`）。
12. **特色词缀 = 机制改变型**：绝世（5~6 词缀）含一条**改变机制**的词缀（如"你的中毒会传染"），复用 `condition + primitive` 表达，**引擎零新增**。
13. **洗练上限**：MVP 数值只由 tier 决定（低层掉不出 T3）；底材声明的**品阶范围在数据上锁死天花板**，洗练再多次也出不了更高阶。
14. **离线掉落 = 玩家可选**：`lootPostProcess: keepBest | allMaterials | lootBox | keepAll` + 参数 N（默认 `keepBest`：按评分留最好的 N 件，其余分解）。共用"掉落生成 → 后处理"管线，区别只在后处理策略。
15. ⚠️ **两个维度不可混**：**秘境层数** → 装备有多强（深度）；**境界** → 能进哪些秘境、哪些底材入池（gating，广度）+ 提供裸装基础数值。

## Considered Options

- **难度靠配表**（每层写死怪物强度与数量）：被否——难度无法涌现，且每层都要人工配平；定时波次让"清怪 vs 生成"的比值自然产生难度曲线。
- **探索结束统一结算掉落**：被否——掉落记录需跨会话存档；即时入库 + 会话内记录 = 零新增存档字段。
- **底材用 `itemLevel` 单条目 + 等级缩放**：被否——高层应掉"另一个底材"（换名字/描述/美术），且 `ADR-0003` 的资产按 id 引用天然支持每底材一图标。
- **底材偏好用显式词缀列表**（每底材列举可出词缀）：被否——新增词缀需改所有底材；标签化让新词缀带上 `tags` 即自动被青睐，零改动。

## Consequences

- 四参数全在 config → 调难度/节奏不动引擎；`maxConcurrent` 是技术护栏，不得当作难度旋钮使用。
- 离线 O(1)：波次公式与 ADR-0010 的稳态 DPS 共同提供离线推进的解析解；任何"必须逐步模拟"的层机制都会破坏它。
- 掉落链是管线配置 → 将来加步骤（如保底、幸运值）不改引擎；但每步的顺序与因果关系（稀有度因 → 词条数果）不可颠倒。
- 校验器可做三类结构检查（连通性闭环、境界段覆盖、每层段每槽位至少一个底材），把内容设计的正确性前移到 `content:check`。
- 标签化倾向让词缀池可独立扩张（新增词缀零改动），代价是权重调参只能靠 `加成` 系数，粒度较粗。
