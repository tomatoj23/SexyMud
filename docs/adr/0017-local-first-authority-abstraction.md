# 单机优先 + 权威端抽象：世界模拟在本机，服务端只做存档与社交

首发无服务端依赖，世界模拟全在客户端；但第一天就把「谁来当权威端」抽象成端口，使将来转网游只需换实现、不换引擎与界面。

## Context

ADR-0002 已定「核心逻辑平台无关、后端用 CloudBase 承担云存档与排行榜」，但从未定义**权威边界**——世界状态在哪一侧演算、命令在哪一侧裁决。文字 MUD 天然有网游形态，若不先划界，将来要么重写，要么永远锁死在单机。

## Decision

1. **定案：单机优先 + 薄服务端**。首发运行时零服务端依赖。服务端只承担三件事，按优先级：**① 云存档（跨设备续档）② 排行榜 ③ 聊天**。世界状态共享（多人同房间、共享战斗、玩家间交易）明确推迟，不在 MVP。
   - 理由：网游的真实增量全是**非内容工作量**——常驻进程、世界状态并发、断线重连、同房间广播、防作弊、运维值班，工作量 ×2~3，且不在本项目优势区（内容生产）。而文字 MUD 的「多人感」主要来自**排行榜与聊天**，这两样一层薄服务端即可拿到。
2. **新增 `Authority` 端口**（与 `Clock` / `Rng` / `SaveStore` 同构，落在 `packages/core/src/types.ts`）：
   ```
   Authority {
     dispatch(command: Command): Promise<CommandResult>   // CommandResult = { seq, events: GameEvent[], rejections? }
     subscribe(listener: GameListener): () => void
     snapshot(): Promise<Snapshot>
   }
   ```
   `LocalAuthority` 直接包 `core` 的本地实例；`RemoteAuthority` 命令上行、事件下行。**界面只认这个接口，永远不认实现。**
3. **确定性升级为硬约束并纳入引擎纯度测试**：`core` 内禁止 `Math.random()`、`Date.now()`、`new Date()`、`setTimeout`/`setInterval`；所有随机走注入的 `Rng`，所有时间走注入的 `Clock`。现有「引擎纯度」测试套件扩展覆盖本条。
   - 这是「将来把 core 搬到服务端跑权威模拟」的**唯一前提**：一旦随机或时间泄漏进逻辑，本地与远端序列不一致，无法对拍验证，等于重写。
4. **命令必须是可序列化、可重放的单位**：`dispatch` 返回 **`GameEvent[]`（纯 JSON）**，不返回对象引用。命令携带单调递增 `seq`。原因：同一份返回结构，本地直接喂渲染器，远端经网络序列化后喂**同一个**渲染器。`RemoteAuthority` 负责 ack 与断线重传，core 不感知网络。
5. **存档仍是可导出 JSON 快照**（沿用 ADR-0002）：云存档只是 `SaveStore` 的另一个实现，格式与迁移链不变，保留退出路径与厂商解锁的余地。

## Considered Options

- **直接做网游（第一天上权威服务端）**：被否——增量全是非内容工作量，×2~3；单人开发下风险集中在运维而非玩法，且玩法尚未被验证（先验证玩法，再付运维成本）。
- **纯单机、永不联网**：被否——放弃跨设备存档与多人感；而 `Authority` 抽象的边际成本极低（一个接口 + 一个本地实现），不做等于自断升级路径。
- **单机 + 服务端只做云存档**：部分采纳——云存档是联网阶段的第一优先，排行榜/聊天紧随其后，世界共享仍推迟。
- **服务端跑一部分业务逻辑**（如掉落在服务端判）：被否——与 ADR-0002「服务端不耦合业务逻辑」冲突，且会让本地/远端行为不一致，破坏可重放性。

## Consequences

- **`packages/core` 的纯度是硬约束的硬约束**：任何一处 `Math.random()` 都不是小瑕疵，是让升级路径失效的结构性损坏。代码评审与纯度测试共同守住。
- **命令的幂等与顺序是内容无关的工程属性**：`seq` + 按序执行由 `RemoteAuthority` 保证；core 只保证「同样的输入序列 + 同样的种子 = 同样的事件序列」。
- **单机阶段也要走 `Authority` 接口**：不允许界面直接调 `core` 的 `Game` 门面。看似多一层间接，实际是把「将来搬服务端」的成本从重写降为新增一个实现类——这是硬标准 2（面向未来）要求的预付成本。
- **作弊在单机阶段不作防御**，但**存档可导出意味着玩家可自改**：因此排行榜只接**服务端校验过的指标**（云存档快照的摘要），或明确标注为「自报成绩」。这条在联网阶段定案，不阻塞当前工作。
