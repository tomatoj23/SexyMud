# 进度主轴改为武功修习 + 空间探索 + 装备构筑，取消境界突破

**取消「境界」作为进度门槛机制**，连同「修为」「突破」两个概念一并作废。进度主轴改为三根并行、全部由在线行为驱动：武功修习（主）／空间探索／装备构筑。

> ⚠️ **翻案**：本文推翻 **ADR-0001**（进度主轴 = 境界突破），并修订 **ADR-0016** 第 1 条（离线结算内容）。

## Context

ADR-0001 定的境界制是**放置游戏**的进度模型：攒修为 → 消耗材料突破 → 数值台阶。它的反馈依赖**等待**，契合离线循环。

但文字 MUD 是命令驱动的在线交互，玩家的进度感应来自「**我能做什么**」而非「我等到了什么」。

**一手证据**（`docs/research/xkx100-content-structure.md`、`xkx100-kungfu-combat.md`）：xkx100——本项目题材与战斗文本的对标对象——**根本没有境界**。它的进度模型是：

- `combat_exp` 实战经验：连续值（100 ~ 100 万），**不是台阶**
- 武功等级：0 ~ 300+，**招式按等级逐档解锁**（黯然销魂掌 17 招的解锁点 `0,10,20,30,40,60,70,80,100,110,120,140,150,160,170,180,200`，越往后间距越大）
- 潜能 `potential`：学武的货币；练习则消耗气血与内力
- **50 档中文品阶**（不堪一击 → 返璞归真）是「等级 ÷ 固定步长」映射出的**显示层**，不是门槛
- 内容按**经验段**分层（任务阶梯 0–2k / 5k–10w / 10w–1kw），构成生命周期地图

即：MUD 传统的进度感来自「会多少招、去得了哪、打得过谁」，与「攒够材料升一阶」是两种设计。

## Decision

1. **取消境界门槛机制**。不再有「攒修为 + 消耗材料突破」这条轴。术语「境界」「修为」「突破」随之作废（从 `CONTEXT.md` 移除或改写）。
2. **进度主轴改为三根并行**，且全部可被命令驱动：
   - **武功修习（主）**：武功条目带**等级**，等级解锁招式动作与文本变体（沿用 xkx 模式，解锁间距递增）。学武消耗**潜能**，练武消耗**气血／内力**——都是在线行为。
   - **空间探索**：区域／秘境带**战力门槛**（非境界门槛），打得过才去得；解锁链是显式字段，供校验器检查连通性。
   - **装备构筑**：沿用 ADR-0005（掉落驱动），不变。
3. **「造诣」取代境界成为公共强度语言**：50 档显示档位（`config/display-tiers.json`）**保留**，但推导来源改为**武功等级 + 实战经验**（xkx 原味），不再是境界下标。它是纯显示层，**不产生任何门槛**。
4. **离线结算改写**（修订 ADR-0016 第 1 条）：离线只补**气血／内力恢复**与**基础武功修习进度**（打坐练功，带上限）。**不再有「离线攒修为」——因为修为概念已删除**。
5. **内容的分层锚改用「推荐战力区间」**，不再用境界区间：每个区域／秘境／任务条目带 `recommendedPower: [min, max]`，校验器据此检查生命周期各段都有内容覆盖。比境界区间更细，且不依赖已删除的概念。

## Considered Options

- **保留境界突破（现状）**：被否——反馈依赖等待，与 MUD 的命令驱动本性冲突；且一手调研显示 MUD 传统里没有这个机制。
- **彻底删除境界、不留任何强度语言**：被否——玩家需要「我多强、别人怎么看我」的公共尺度，否则 NPC 态度、任务门槛、玩家自评同时失去锚点。
- **境界改名为「江湖地位」但保留突破动作**：被否——换名不换机制，仍是等待型门槛，只是绕开字眼。
- **改用纯等级制（Level 1-99）**：被否——题材词汇红线（CONTEXT 明令 `_Avoid_: 等级`）；且等级是西幻/网游语汇，与武侠白描冲突。武功等级是逐技能的，与角色等级不同，不冲突。

## Consequences

- **翻案与同步清单（已于 2026-09-01 全部执行完毕）**：ADR-0001 已推翻；`CONTEXT.md` 删除「境界／修为／突破／闭关／突破丹」并新增「实战经验／武功等级／练功／潜能／造诣」，「显示档位」改为纯显示机制；`content/config/realms.json` 与其 schema 已删除；`martial` schema 的 `prerequisites.realmIndexMin` 已改为 `martialLevelMin`，`dungeon` 的 `recommendedRealmIndex` 已改为 `recommendedPower` 区间；`packages/core` 的 realm 相关类型与门面方法已删除；HANDBOOK 定案速查表已更新。
- **收益**：进度全由在线行为驱动，与 ADR-0016「MUD 为主」完全一致；且直接复用 xkx 的「招式按等级解锁」成长曲线，内容生产有现成蓝本。
- **风险与补偿**：失去台阶式的强进度节点（境界突破本身有仪式感）。补偿两处——① **招式解锁自带文本仪式**（解锁新招时给一段专属描写）；② **门派辈分晋升**（xkx 的字辈：澄 → 道 → 玄），是社会层面的台阶，成本只是门派条目里的一个字段。
