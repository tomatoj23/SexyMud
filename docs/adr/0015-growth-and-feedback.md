# 成长与反馈：突破时的偏向选择替代天赋树，变强感靠纪录与叙事分档，专精靠词缀涌现

> ⚠️ **部分失效（2026-09-01）**：境界突破已取消（ADR-0019），因此本文第 1 条的「突破时的偏向选择」**失去载体**（它原本复用突破界面）。替代载体见 ADR-0019 的补偿方案：**招式解锁仪式 + 门派辈分晋升**。
> **仍然有效**：不建天赋树的理由、变强反馈四条补法（B 秘境推进记录 / C 战斗新纪录 / D 叙事化反馈）、定向强化涌现式专精（词缀 `condition: { moveId }`）、长期成长两条线。
> **已被 ADR-0020 加强**：D（叙事化反馈）扩展为**战斗摘要**与**同对手对照**，成为成长反馈的主力机制。

**不建天赋树**——修为是闭关自动产出，未分配点数会变成作业。取而代之：境界突破时给 2-3 个偏向选项（共 6 次），复用突破界面，无新系统。中频的"变强反馈"用**纪录 + 叙事分档**补（成本极低到零），定向强化用**词缀 `condition: { moveId }`** 让"专精"涌现（系统里从来没有叫"专精"的东西）。

## Context

放置游戏的成长节奏与 RPG 天赋树天然冲突：天赋点需要玩家主动分配，而放置的修为是离线自动产出的——玩家离线八小时回来看到 20 个未分配点数，那不是反馈，是作业。同时"中频反馈缺失"是体验短板：境界（低频）与掉落（高频）之间，缺少"我确实变强了"的可感知信号。另需回答"长期成长靠什么"——数值线（打更高级内容）与构筑线（用不同方式打）两条。

## Decision

1. **突破偏向选择（替代天赋树）**：复用境界突破界面，每次突破给 **2-3 个选项，共 6 次**；选项与已定的 `source`（内功/外功）维度咬合，例如：外功精进（外功招式伤害 +10%）／内功深厚（内功招式伤害 +10%）／根基扎实（生命上限 +8%、内力上限 +8%）。**不要做成树**。
2. **变强反馈四条补法**：
   | 补法 | 内容 | 成本 |
   |---|---|---|
   | A. 强度聚合指标 ⏸ | 聚合连续数值。**命名待定**（战力被用户否决、"等级"与 CONTEXT.md Avoid 冲突、"功力"为候选）。若不要聚合数字，A 可整个跳过 | 中 |
   | B. 秘境推进记录 | "已推进至第 18 层（历史最佳 15 层）" | 极低 |
   | C. 战斗内新纪录提示 | "最高伤害 3,847！"——记录**每一招的最高伤害** | 极低 |
   | D. 叙事化反馈 | 战斗文本分档系统本身就是反馈机："血线缓缓渗出" → "皮肉焦黑" → "连人带剑被劈作两段" | **零** |

   ⚠️ **A 的聚合函数本身必须存在**——即使展示命名未定，离线掉落的 `keepBest` 策略已依赖它（ADR-0012）。
3. **定向强化（涌现式专精）**：采用词缀定向强化 `condition: { moveId: "..." }`；**保留镶嵌 / socket 的数据预留**（ADR-0005 已声明）。玩家从不"选择专精"，只是反复挑强化同一招式的装备——挑够三件就成了专精，但**系统里从来没有叫"专精"的东西**。
4. **长期成长两条线**：
   - **数值线**（能打更高级的内容）= 底材分层 + 词缀阶位；
   - **构筑线**（能用不同方式打）= 机制型特色词缀 + 七系主辅组合 + 兽的机制放大器（ADR-0013）+ 境界突破偏向选择。

## Considered Options

- **天赋树**：被否——与放置品类冲突（修为自动产出 → 未分配点数 = 作业）。
- **显式的"专精"系统**（玩家选专精方向）：被否——流派不预设标签（CONTEXT.md 流派词条）；改为让专精从装备选择中涌现。
- **战力数字作为主要反馈**：被用户否决（"成了那些垃圾页游"）；聚合函数保留（离线掉落依赖），展示层可整个跳过。

## Consequences

- **聚合函数是离线掉落 `keepBest` 的硬依赖**：命名与展示可以拖，函数必须在引擎里存在。
- 突破偏向选择 = **内容条目**（每次突破的选项组），加/改选项不动引擎。
- B / C 两类纪录是**存档字段**（"历史最佳层数""每招最高伤害"）→ 纳入版本化存档迁移范围。
- D 是零成本的：战斗文本分档（ADR-0011 的 5 维分池）天然就是强度反馈机，无需额外系统。
