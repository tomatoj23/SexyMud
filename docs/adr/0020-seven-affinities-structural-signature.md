# 七系改用「结构签名」而非系数：让系别、构筑与成长在纯文本中可被看见

**七系保留，但必须从「数值系数」升级为「结构签名」**——每系必须占住一个**可被文本观测的结构维度**，且七系互不相同。禁止任何一系以「纯数值系数」形态存在。同时定案三层反馈机制（战斗摘要／同对手对照／社会称呼），回答「如何直观感受 build 与成长」。

> ⚠️ **修订**：本文作废 **ADR-0009** 的「MVP 形态：2 真状态（木·中毒、火·灼烧）+ 5 纯数值」。

## Context

### 问题：纯数值差异在文字媒介里等于不存在

ADR-0009 定的七系（金木水火土风雷 → 破防／疫毒／滞缓／燃爆／守护／迅疾／霆爆）在 MVP 里有 **5 个是纯数值**。在图形游戏里这能接受——血条掉得更快、飘字更大、粒子更亮。

但文字游戏没有血条与飘字。玩家堆了一身风系词缀，进战斗看到的文本**和之前一字不差**，只是背后的数字大了 12%。他感受不到，也说不出来。**5/7 的系别在 MVP 里等于不存在，却占着七系的设计、内容与校验成本。**

### 一手证据：文字游戏里"可被看见"的是什么

xkx100 没有元素系，但它的全部战斗反馈都靠文本，其手段只有四类（`docs/research/xkx100-kungfu-combat.md` §6）：

- **档位递进**：伤害分档文案 6-9 档，从「只是轻轻地划破皮肉」到「深及见骨的可怕伤口！！」，**最后档必带双感叹号**——它的"暴击特效"就是措辞升级加标点
- **周期文本**：中毒等状态按周期扣血并输出一句（`condition/poison.c` 的 `info["message"]`）
- **频次**：左右互搏「双手分使，好象变成了两个人似的」——出手数直接写进文本
- **专属事件**：闪避时特殊轻功输出带招式名的华彩文本，**轻功的"人格"完全由这组文本表达**（它没有招式表）

结论：**文字媒介中玩家能感知的只有离散的、可命名的事件，不是连续数值。** 能被观测的维度只有五种——**频次、节奏、档位跃迁、事件触发、状态词条**。

### 推论：判据

本 ADR 采用一条硬判据：**关掉所有 UI 面板，只读战斗文本，玩家应该能说出"我这套是火系还是风系"。做不到，就说明该系的签名没生效。**

## Decision

### 1. 七系的结构签名（每系占一格，七系互不相同）

| 系 | 轴 | 签名类型 | 玩家读到的文本 | 实现机制 |
|---|---|---|---|---|
| **金** | 破防 | **档位跃迁** | 「剑锋崩开他护心镜的系绳」→ 此后伤害描述档位 +1 | 减防 condition |
| **木** | 疫毒 | **状态 + 节奏 + 传染** | 「创口泛起一层青黑」→ 每回合「毒气又深入一分」→ 可染及旁人 | DoT condition + 传染目标选择 |
| **水** | 滞缓 | **对手频次下降** | 「他出手凝滞了半分」→ 对手攻击间隔延长 | 减速 condition |
| **火** | 燃爆 | **节奏 + 爆发事件** | 「焦臭气冒起」→ 每回合灼烧 → 叠满「轰的一声，火舌炸开」 | DoT + 叠层爆发 |
| **土** | 守护 | **自身受击档位下降** | 「土黄色的劲气附体」→ 受击描述档位 −1 或直接「被挡下」 | 减伤 condition |
| **风** | 迅疾 | **自身频次上升** | 「身形一晃已是两招」→ 攻击间隔缩短 | 提速 condition |
| **雷** | 霆爆 | **事件触发** | 「雷霆自掌心生出」→ 暴击／连锁，专属文本 + 会心金框 | 暴击修饰符 |

**两条关键性质：**

- **数值上等价的东西，在文本上是不同体验。** 风（自身提速）与水（对手减速）在伤害公式里几乎等价，但「身形一晃已是两招」和「他出手凝滞了半分」是两种完全不同的爽感。火与木同为 DoT，靠「焦臭／火舌」与「青黑／毒气」两套词库区分，且火有爆发、木有传染。**这是文字媒介的独有红利，不是妥协。**
- **签名必须可被玩家命名。**「我这套是火烧流」「我是靠毒磨的」——说得出名字，系别才算真的存在。这是比数值平衡更优先的验收项。

### 2. 战斗摘要：战后一行画像

战斗结束输出一行结构化摘要。**每一项都由结构签名产生，不由伤害统计产生**——这保证了 build 一变，摘要立刻变。

> 例：「十七合，你出手九次，四次切中要害；**火烧掉了他三成气血**；三次被他格开。」

堆风系的人看到「出手九次」（别人六次），堆火系的人看到「火烧三成」，堆土系的人看到「三次被他格开」变成「一次」。**摘要本身就是 build 的指纹。**

摘要模板是内容（`content/config/`），条目按签名类型声明，引擎只做「取该场触发过的签名条目、按模板拼一行」。

### 3. 同对手对照：昨我 vs 今我

存档记录每个对手的上次交手结果（`lastEncounter[monsterId]`），再次交手时**自动对比**：

> 「三日前你在此处苦战三十合方险胜，今日十一合便将其击倒。」
> 「上次他的掌风逼得你连退七步，这一次你只退了两步。」

**这是文字游戏独有的成长反馈**——只有文本战斗才留下可读的痕迹。图形游戏的战斗打完就消失了，文字游戏的战斗留下一份可以拿出来对比的记录。这是本作相对图形游戏的结构性优势，不是可选项。

### 4. 反馈节奏（定案五层）

| 层 | 时间尺度 | 载体 | 玩家感受到的 |
|---|---|---|---|
| **即时** | 一次攻击 | 后果词档位跃迁 + 会心金框 | 「划破皮肉」变成「深及见骨！！」 |
| **一场** | 一次战斗 | 战斗摘要一行（§2） | 「火烧掉了他三成气血」 |
| **跨场** | 重访同一对手 | 同对手对照（§3） | 「三十合 → 十一合」 |
| **长线** | 武功升级 | 招式解锁 + 文本变体升级 | 黯然销魂掌 200 级解锁「魂不守舍」，带专属描写 |
| **社会** | 长期 | 50 档造诣 + NPC 敬称变化 | NPC 从称「后生」变成称「少侠」 |

**措辞升级就是文字游戏的特效。** 不需要飘字与屏震——「像一捆稻草般飞了出去！！」那两个感叹号承担的，正是暴击特效的功能（ADR-0006 已定：视觉层降级为辅助，强度差异由叙事档位表达）。

**社会层成本极低、收益极高**：NPC 敬称由造诣档位驱动，是内容表条目（`rank_info/respect`，xkx 已验证的模式），不是引擎逻辑。

### 5. 协同必须可见（1+1>2 的瞬间）

系别组合的收益要**在文本里发生**，而不是在结算里发生：

- **风 + 火**：出手变快 → 灼烧叠得更快 → 爆燃更早触发。玩家读到的：「这一次火舌炸开，比上次早了两合。」
- **金 + 雷**：破防提高伤害档位 → 暴击落在更高的档位上 → 文本跃迁更夸张。
- **木 + 水**：毒靠回合跳，水让对手出手变慢 → 同样回合数内毒跳更多次。

**反面也要可见**：对手的亲和度（ADR-0009 的 `affinities`）必须产生文本——打水系对手用火系，应读到「火舌刚起，就被他身上腾起的湿气压了下去」。**被克制的挫败感同样是系别存在感的来源**，只做正向反馈会让七系变成七个增益按钮。

## Considered Options

- **七系保留为纯数值系数，靠 UI 面板解释**（显示「风系加成 +12%」）：被否——把体验外包给面板，玩家读战斗文本时依然无感；且 ADR-0006 已定叙事层是绝对主体。
- **砍到 2~3 系**：**部分采纳，作为降级预案**——见 Consequences。
- **七系各配一种独立状态**（7 种 DoT/异常）：被否——状态堆叠会让文本与战斗节奏失控。本方案的七系只复用**四类机制**（档位／节奏／频次／事件），成本低且互不打架。
- **靠伤害数字变大体现**（数字跳动）：被否——ADR-0006 已定伤害数字行内嵌入、不是主体；且裸数字缺上下文，120 → 135 不可感知。
- **加强视觉层**（血条分段掉血、系别配色闪光）：被否——与 ADR-0006「叙事 >> 视觉」的定调冲突，且小程序端几乎无法承载。

## Consequences

- **ADR-0009 的「2 真状态 + 5 纯数值」作废**，改为「7 结构签名」。
- **新增内容需求**：七系各一套专属措辞（后果词库第 5 维「系别」已有，ADR-0011）；`content/config/` 需补状态周期文案表、战斗摘要模板、NPC 敬称表。
- **存档新增字段**：`lastEncounter`（对手交手记录），需走版本化迁移链（ADR-0002 已有机制）。
- **降级预案（硬性）**：M1 结束时逐系验收「关掉面板、只读文本能否说出系别」。**任何一系验收不过，就砍掉它**，而不是让它以系数形态赖在内容里。宁可只有 4 个真系，不要 7 个假系。
- **验收方式**：一次盲测——给读文本的人两场战斗记录（不同 build 打同一对手），他能说出两个 build 的差别，即通过。

> **待办（不在本文定案）**：七系签名落到 `content/effects/` 的具体条目设计，与「系别 × 方式（内功/外功）」2×8 矩阵的交叉验证（ADR-0009 未覆盖签名形态下的矩阵语义）。
