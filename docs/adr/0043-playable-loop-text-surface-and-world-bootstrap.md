# 可玩闭环（世界引导＋游戏界面）：文本面随引擎出厂＋世界引导表＋终端基准端＋存档闭环

架构评审队列（#32–#47）收官后的下一程（#48，2026-10-05 grill 三轮定案 R1–R3 共 16 条＋Q1–Q8 裁决，owner 逐轮确认）：把 core 的「走/看/说」接进 `apps/web`，长出**可玩闭环**——标题屏 → 世界引导落起始房间 → 追加式终端走/看/说 → 每命令自动存本地档。拆五票全关：**#49** 世界引导内容面／**#50** 文本面出厂／**#51** 可玩一发（tracer）／**#52** 存档闭环／**#53** 输入组件（2026-10-24～10-26）；规格快照＝#48 本身。立否三条件自评：**难逆**（引擎公共契约新增 `src/text/` 全族＋`RenderContent` 注入面、spec/05 §1 原句被翻、web 呈现层与后续票按它写、`world.json` 表＋content:check 第五道检查、存档 `name` 槽＋`unfilled` 缺席策略进 SLOT_RULES——撤回波及引擎公共面＋门禁＋存档形状＋两端呈现）／**会困惑**（「spec/05 §1 为什么曾说『渲染、分块、呈现全在宿主』、现在是引擎出厂」「取字表为什么入参注入而不是渲染器读注册表」「enterText 为什么宿主直出、不走事件」「startRoomId 为什么不进 settings」「可达性为什么豁免模板房」「房间从内容包消失为什么不是坏档」无记录必读不懂——工作稿在临时区会清）／**真权衡**（渲染留宿主各写／settings 加字段／可达性落注册表或双落／customEvent 兜底渲染／resize 全量重排／手动存档／角色创建表单等被否路线三表在案，含 Q1/Q2 翻案）——三条齐，立。

## Context

- **设计输入**：`.scratch/archive/playable-loop/DECISIONS-WIP.md`（D1–D16＋三张被否表＋Q1–Q8 裁决并入；本 ADR 立批随票收官归档）、`GRILL-OPEN-ITEMS-2026-10-05.md`（裁决全文，同目录）；spec/05 §9 `TerminalView` 基准端（ADR-0018）；spec/07「CJK 显示宽度、避头尾折行属引擎侧职责」；ADR-0003（形状归 content:check、引用归注册表的分层）；ADR-0022 §8／ADR-0025 §八（可点击命令只来自引擎/内容侧——输入加固的既定方针）。
- **票前事实**：引擎内核能走/看/说（合成驱动全绿）但 `apps/web` 只是云存档面板——浏览器里看不到任何游戏；`spec/05` §1 原句「渲染、分块、呈现全在宿主」；core 已有出厂适配器先例（lookSpec/saySpec，M2-T2/T3）；事件封闭联合五型（#47，后 #56 扩八）；中文清单 B8（避头尾）与 G3（IME）是已绑定验收条件。

## Decision

1. **切片边界＝最小闭环＋本地存档**（D1）：新档 → 落起始房间 → 走/看/说 → 渲染成文进输出窗 → 自动存/读档续玩（`SaveStore` 端口接既有 `LocalSaveStore`）；云档接入游戏会话、时间体验上 UI、get/give/drop 转移命令出列（云档留单立票、后两者随机制面）。
2. **文本面随引擎出厂**（D3，Q3 收准）：渲染纯函数 `renderEvent`（事件 → `OutputLine[]`，含 Actor stance 换人称、拒绝文案查内容取字）＋**显示宽度/避头尾折行/切块与 span 重放**（`src/text/` 五件：line/width/wrap/chunk/render）一份各端共用——与 lookSpec/saySpec 出厂适配器同族叙事（引擎词汇出厂，宿主只做呈现与喂参）；**翻案 spec/05 §1 原句**「渲染、分块、呈现全在宿主」为「渲染、折行、切块随引擎出厂，宿主只做呈现与喂参」（依据 spec/07 引文：CJK 显示宽度、避头尾折行本就是引擎侧职责——「换端不重写」）。取字表/名字表/enterText 随渲染器**第三参注入**（Q6：纯函数零 IO、零注册表读，接线失配大声抛错）；宽度与视口高度都是切块器**入参**（Q4，web 首刀喂固定 40×24、接口不写死）。
3. **首批渲染面＝封闭联合五型全覆盖**（D9）：appearance／say／departed／arrived／commandRefused（arrived 渲染含目的地 enterText——Q7 移动半边）；**customEvent 显式不渲染**（注释点名＋测试钉，渲染缝随机制模块票再定——#56 战斗三臂兑现此缝）；拒绝渲染 `errKey→errCopy` 优先、语义码→`reasonCopy` 兜底。
4. **起始房间＝内容包声明**（D2/D8，Q1 翻案）：`content/config/world.json` **世界引导表**声明 `startRoomId`（将来引导语汇同表），换包即换起始房间、引擎零题材词。翻案依据：spec/06 三分法硬约束「settings 只收数字、结构性配置另开文件」（dimensions/display-tiers/calendar 先例）＋原「settings 加字段」立论系改字引文。**可达性归 content:check**：离线 BFS（起始房间为根、报告不可达房间 id），覆盖＝**非模板房间**（声明 `prototypeKey` 者豁免——Q2：模板是坯子不是玩家走得到的房，迷你包 `room-orb-000` 系模板兼房间且无入边、字面全可达对现夹具为假）；**双句归层**（Q8，沿 ADR-0003）：`world.json` 声明缺失归 content:check、`startRoomId` id 悬空归注册表加载期引用校验（该校验随 #49 加，与出口 `targetRoomId` 同律）；迷你包是测试夹具不在门禁范围、可达性由 mini-pack 测试钉。
5. **进游戏流程＝标题屏＋世界引导**（D14/D15）：「新游戏/继续」两按钮（有档才亮「继续」——bytes-exist 探针）＋名字框（空则默认「少侠」，应用点在宿主——Q5 题材词红线）；**单档**，新游戏覆盖旧档前确认一次（in-UI 确认条，不用 `window.confirm`）；新档落 `startRoomId` 后**先读 enterText 到达叙事、再自动 look**——enterText 由**宿主直出为输出行**（Q7：不经事件、不新增事件型，封闭联合不破），零新内容字段。
6. **玩家角色＝名字一行**（D13）：名字是显示字段进存档载荷（`name` 槽，第三种缺席策略 `unfilled`——缺席即无名、默认归读者侧，引擎不写不猜）；**actor id 固定 `player`、不从名字派生**（单机单档下 id 与名字解耦——G2 联网重名的 id 面不被提前锁死）；重名/混淆检查（G2）随它自己的票。
7. **终端界面照 TerminalView 基准端**（D4/D10/D16）：纯 TS 状态机（追加式输出＋`setStatus`＋`onCommand`＋`setSuggestions` 留口空实现），React 只做呈现（`white-space:pre` 不折行——**追加即定稿、resize 不重折**）；输出缓冲上限 **500 行**超出丢最早行＋稳定行 id；**状态行＝所在房间名＋游戏内时辰**（历法纯函数 `segmentOf` 推导；时辰显示名后经 owner 裁决〔#51 D2，2026-10-25〕进内容包 `segments[].label`——「内容取字」按字面落，缺省回退裸 id）；**绑定表**＝宿主侧一张「命令 id → 出厂行为」表（换包换表，mini-pack 先例）；输出统一过引擎切块器。
8. **输入组件＝IME 合成守卫＋命令历史**（D5）：G3 双条件（composingRef＋`isComposing`，compositionend 后一宏任务宽限兜 WebKit 时序）——合成中 Enter 不提交半成品、方向键让路候选窗；命令历史上翻/下翻**会话态不落盘**（「未显式写入的字段不落盘」同律）；输入加固取最小面（输出按 token 渲染、玩家输入原样显示不解释 markup——§8 全量随机制面，#54 后来落地并验证此切分）。
9. **存档闭环语义**（D7）：每条命令结算后自动存（手动存档不做）；续档回存档位置；存档房 id 在当前内容包查无此房 ⇒ **回退起始房间＋一行提示**——**不判坏档**（「房间没了」是内容演进不是载荷损坏，坏档判定归载荷损坏大声失败的既有口径专责；宿主 `continueGame` 装配前预检是引擎「内容漂移大声失败」律的**唯一例外注**，两类不混判）；命令历史＝会话态。
10. **文风口径顺手裁**（D6/D12）：B9 中英混排空格（盘古之白三则）＋C5 四字格降自由裁量，进 `content/style-guide.md`「排版与节奏」——零代码决策当批即落。
11. **测试分层＝四条缝**（D11，owner 确认——越少越高）：①**引擎纯函数面**（渲染五型逐事件＋折行/切块宽度入参＋B8 禁则表逐条参数化，先例 save-summary 纯函数钉）②**panel-rig 渲染面**（jsdom：标题屏/终端界面/输入组件全在一缝，先例 mountAuthPanel）③**既有命令 harness 端到端**（世界引导落点与命令→事件→渲染接线，不新开缝）④**content:check 可达性门禁**（沿「无单测、手工验证」先例；迷你包可达性进 mini-pack 测试）。G3 IME 带**真机手验清单**（iOS／Android／桌面各一：合成中 Enter 不提交、合成完成正常提交）——jsdom 钉不住真机行为，须真验（#53 关票时 2026-10-26 三端全过留痕）。好测试只测外部行为（输出文本/事件序列/存档载荷/可见状态），不测实现细节。

## Considered Options

（被否路线全文见 `.scratch/archive/playable-loop/DECISIONS-WIP.md` 三张被否表＋Q1–Q8 裁决）

- **渲染留宿主各写（维持 spec/05 §1 原句）**：立场表与拒绝文案取字两套实现必然漂移；spec/07 引文已把宽度/避头尾列为引擎职责。
- **渲染器读注册表取字**：纯函数破功（Q6）；取字表入参注入保零 IO。
- **enterText 走新事件型**：封闭联合（#47）为一条开场叙事破例不值（Q7）；宿主直出。
- **`startRoomId` 进 settings**（Q1 翻案）：spec/06 三分法「settings 只收数字」硬约束；原立论「字段随消费它的系统落地」系改字引文（源句「**数字**随…」）。被否变体：settings 分组内塞、settings 第十类。
- **房间 schema 加 `start` 标记／宿主参数传起始 room id**：多起始房间语义发糊、schema 管形状不是引导层；后者引导脱离内容、换包不换起始房间。
- **可达性落注册表加载期／双落**：作者期图性质归 content:check（ADR-0003 分层），装载期重复跑无谓；字面全可达不豁免模板——对现夹具为假（Q2）。
- **customEvent 兜底渲染／现在开渲染注册缝**：首切片零 customEvent；缝随机制模块票（#56 战斗三臂分派＋`RenderCopy` 固定模板键兑现）。
- **resize 全量重排**：违 `appendOutput` 增量追加契约（追加即定稿）。
- **手动存档按钮／命令／手动＋自动**：localStorage 同步、命令节奏慢，自动存足够。
- **命令历史进存档**：「未显式写入的字段不落盘」同律，会话态。
- **位置失效当坏档大声失败／静默回退**：内容演进不是载荷损坏／静默丢叙事——带一行提示回退。
- **固定角色名／角色创建表单／直接进游戏菜单**：表单超出「能玩」；存档管理面不是进游戏的门面。
- **单档静默覆盖／多槽位**：静默丢进度不可接受；本地不做两套槽位 UI（多槽是云档已有面）。
- **新增开场白内容字段／只 look 不带 enterText**：零新字段先行；`room-lq-001` 的 enterText 天然开场。
- **输入加固 §8 全量进首刀**：可点击命令等随机制面（#54 落地全量＝`sanitizePlayerInput`＋markup 码位隔离）。
- **时辰显示名住宿主词表**：#51 实现期先落宿主（calendar 段只有 id），owner 随裁进内容包 `segments[].label`——词是包的词汇、与房间 `name` 同律。

## Consequences

- spec 升级随五票各自落地：spec/05（§1 翻案句＋§2 渲染面＋§5.2 宽度注入＋§9 终端基准＋§10 自检清单全勾，后经 #53/#54/#55/#56 增补）、spec/06（三分法 STRUCTURE 行＋§3 门禁清单第五道）、spec/04（`name` 槽 `unfilled`＋§1.4 宿主预检例外注）、spec/02（取字表注入句）、spec/07（§5 勾四项）、spec/00 状态行、CONTEXT（起始房间/世界引导词条）、`content.md`（世界引导表节）。本 ADR 随 #48 收口补落 D13 半句（玩家实体 id 固定 `player`）进 spec/04 §1.4。
- 引擎纯度红线全程保持：渲染/折行/切块零题材词（取字表、默认名、提示文案全宿主注入——Q5/Q6）；`engine-purity` 扫描照过。
- 后继票验证了本 ADR 的切分预判：渲染缝随机制模块票（#56 战斗三臂）；输入加固全量随机制面（#54）；宿主壳面自成一票（#55 回标题门）。
- 已知债务／后续：云档接入游戏会话（留单）；移动三件套余两件（快捷条/补全——历史回溯已随 #53 落第一片）；G2 重名与视觉混淆、A6 全角归一化、清单 D4 模糊命令建议（各自小票）；时间体验上 UI 随机制面。
