# 进度主轴采用境界制，门派与流派二分

> ⚠️ **已作废（2026-09-01）**：本文的「进度主轴 = 境界突破」由 **ADR-0019** 推翻。境界、修为、突破三个概念**全部取消**，进度主轴改为武功修习（招式按等级解锁）+ 空间探索 + 装备构筑三根并行。一手依据：xkx100 根本没有境界，其进度是实战经验 + 武功等级 + 造诣显示层。
> **仍然有效**：门派与流派二分（门派决定可学武功池、流派由装备 + 武功装配涌现）、不预设流派标签。

游戏对标梅尔沃放置，但不照搬其"技能等级"进度模型：进度主轴改为**境界突破**（修为积累 + 材料门槛），生产、采集、战斗全部服务于突破。同时把"门派流派"拆成两层正交概念：**门派**决定可学武功池（收集驱动力），**流派**是装备+武功装配涌现出的战斗构筑（构筑乐趣）。MVP 不预设流派标签，给足武功/装备自由度让流派自然出现。

## Considered Options

- 换皮派（技能等级改名武功，结构照搬）：被否——题材差异化不足。
- 一体派（选门派=锁定流派）：被否——构筑失去混搭乐趣，"偷师/换派"也无法成为玩法。
- 预设流派标签（每门派预设 2 流派）：被否——容易做死，MVP 只保证机制支持涌现。

## Consequences

- 突破采用 100% 成功率 + 材料门槛，炼丹链因此有明确目标；走火入魔（失败惩罚）明确推迟到后续版本，避免放置玩家遭遇不可控负反馈。
- 修为只来自闭关，战斗产资源/秘籍/装备：两条资源线并行，互不挤压。
- 离线收益为全额但有上限（闭关有期限），制造回归钩子。
