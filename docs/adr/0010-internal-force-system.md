# 内力系统：持续回复 + 稳态 DPS 离线 O(1) 结算，代价在另一个维度付账

> ⚠️ **部分失效（2026-09-01）**：本文的「**稳态 DPS 离线 O(1) 结算**」依赖「离线自动战斗」这一前提，而 ADR-0016 已定**离线不自动战斗**。离线只补气血/内力恢复与基础熟练度（ADR-0019），无需稳态公式。
> **仍然有效**：持续回复模型、内力耗尽 → 零消耗基础攻击（输出降级不归零）、代价在另一维度付账、全部参数在 config、七系以内力为性格载体。
> **已修订**：上限来源由「境界」改为「**武功等级**」（ADR-0019）。

内力 = 战斗中**按秒持续回复**的战斗资源（模型 A），招式消耗内力。离线用**稳态 DPS 公式**（收支平衡点）**O(1)** 结算，不模拟时间序列。内力耗尽 → 自动切换**零消耗基础攻击**（用当前兵器的普通攻击），输出下降但不归零。代价设计遵循"不是数值打折，而是在另一个维度上付账"，全部参数在 config（**数值后置**：现在是初值不是承诺）。

## Context

放置游戏的核心结算是离线推进，任何需要"按时间逐步模拟"的资源机制都会让离线结算退化成 O(n) 回放。内力作为唯一的战斗资源（招式消耗它、心法与装备提供它），其回复模型直接决定离线结算能否解析求解；同时"内力耗尽怎么办"决定挂机体验是否中断。另需约束后续七系差异化：内力是系别性格的主要载体（金耗内破防／木寄赖吸内／水滋养／火倾泻／土承载／风轻灵／雷激荡背水）。

## Decision

1. **模型 A：持续回复**。战斗中按秒回内力；**离线用稳态 DPS 公式**（收入 = 支出 的平衡点）**O(1)** 结算。
2. **内力耗尽 → 零消耗基础攻击**：用当前兵器的普通攻击（拿剑挥剑、拿指虎出拳），输出下降但不归零，战斗不中断。
3. **上限来源**：境界 + 心法 + 装备词缀，走 `ADR-0005` 的修饰符聚合管线，**引擎不写死公式**。
4. **内力与内功防御不硬挂钩**（避免堆内力成唯一解）；联动只走内容层词缀。
5. **MVP 最小形态**：上限 + 消耗 + 持续回复 + 零消耗基础攻击。七系差异化留 v2，但"七系 × 内力映射"表已定（金：耗内破防／木：持续寄赖或吸内／水：回复加快或上限提高／火：高耗高爆发易见底／土：上限提高或内力代偿减伤／风：消耗降低或提频／雷：消耗换暴击或背水）。
6. **代价在另一个维度付账**（不是数值打折）：
   - **木 · 吸内四重代价**：不能吸干（目标内力不低于上限 25%）／转化效率低（吸 100 进账 40%）／自身伤害低（携带吸内的招式伤害系数 ×0.7）／可被抵抗（走效果抵抗，「固本」类词缀）。
   - **雷 · 背水**：内力 < 30% 触发，加成 `伤害 ×(1 + 最大加成 × 衰减系数)`，最大 +50%（config）；代价 = 门户大开（外功防御同步下降，伤害 +50% 时防御约 −25%）+ 闪避同比例下降 + 需主动维持（内力自动回复，维持低内力须持续消耗）。
   - **自伤换增益**（不绑定系别）：无视外功防御 / 无视护体（`stat-modifier` 减伤无效）/ 可致死 / 触发濒死档文本选择。
7. **内力是出招调制器之一**（MVP 4 个：冷却／内力／重复衰减／系别亲和）——内力不足使权重降权或归零，而非禁用招式本身。

## Considered Options

- **模型 B：离散消耗 + 不持续回复**（起手扣光、靠击杀或药剂回）：被否——离线结算无法 O(1)，必须逐步模拟"还有没有内力"；持续回复存在稳态解，可解析求平衡。
- **内力耗尽即停手**（无法攻击直到回复）：被否——放置游戏挂机中断体验不可接受；零消耗基础攻击让输出降级而非归零。
- **内力与内功防御硬挂钩**（内力越高内功防御越高）：被否——堆内力成为唯一最优解，压缩构筑空间。
- **代价 = 数值打折**（如"吸内招式伤害 −30%"了事）：被否——只是同一维度上减量，不产生决策；改为在防御/闪避/维持成本等**另一维度**付账。

## Consequences

- 稳态 DPS 是离线 O(1) 结算的前提：任何未来的内力机制（新的消耗/回复方式）**必须保持稳态可解**，否则会拖累离线推进的复杂度。
- 零消耗基础攻击是招式表的一部分（内容），不是引擎特例分支。
- 七系差异化虽留 v2，但内力性格表已定 → v2 直接落 config，不需要改引擎或重开设计。
- 代价设计原则（另一维度付账）约束所有后续系别/词缀内容的设计，防止出现"纯数值强弱"的假选择。
