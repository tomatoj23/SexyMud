# 武学体系·总纲（设计稿）

> **定位**：叙事与机制设计稿，不是 schema 提案。所有武学条目暂存于 `docs/martial/`（Markdown），不进 `content/`、不动 `schemas/`。将来内容生产时按 `martial.schema.json` 落 `content/martial/`，效果落 `content/effects/`。
>
> **依据**：ADR-0009（方式×系别 2×8 矩阵、七系表）、ADR-0010（内力与代价、系别内力性格）、ADR-0011（motion 与文本变体）、ADR-0014（门派三件套与脉）、`docs/engine-reservations.md` §3（效果 primitive 候选集）、`content/style-guide.md`（叙事语体）。

## 一、体系框架：一张矩阵上的三十六般变化

武功 = **招式**（主动，装配 4）+ **心法**（被动，装配 3）。每条武功是矩阵上的一个点：

```
作用方式（source）：内功 ─┬─ 系别（element）：金 木 水 火 土 风 雷 + 无属性
                          └─ 正交：2 × 8 = 16 格
兵器适配：剑 / 刀 / 棍 / 拳掌 /（暗器——见 §五）
品阶：下乘 → 中乘 → 上乘 → 绝学
```

**门派提供缺省系别，不垄断系别**：丐帮（火/雷）、武当（水/土）、唐门（木/金）——三门派恰好覆盖六系，**风系与无属性留给江湖散传**（仅秘籍掉落、无门派兑换途径）。第七格由装备词缀补齐，形成"门派给骨架、装备填血肉、江湖武学开岔路"的构筑三角。

**武功池按脉（lineageId）细分**：每派 2~3 脉，是武功池的归类标签而非身份选择（ADR-0014）。玩家用 4 个招式槽"投票"，同时挂两条脉的武功是常态——混搭即流派。

## 二、命名军规（六条）

1. **写动作与意境，不写系别字眼**。「平地惊雷」可以，「烈焰刀法」不行——系别意象是 `{elementFlavor}` 词库的职责（火系招配上"剑锋赤红，热浪逼人"由槽位填）；招式名若带系别字，换个辅系装备就自相矛盾。例外：自然物象可入名（雷、风、云、江），因为它们是动作意象不是系别声明。
2. **四字格为主基调，三字/五字作变奏**。schema `name` 无 pattern 硬约束（minLength 1），"四字格"是风格指引；金庸三字（打狗棒法体）与五字（黯然销魂掌体）皆有先例。变奏控制在每派 2~3 条，多则乱。
3. **同门风格统一**：丐帮——市井粗豪，成语俚语行话入名（拨草寻蛇、天下无丐）；武当——道家清雅，易经道德经意象（上善若水、厚德载物）；唐门——阴巧狠辣，毒物机关意象（附骨钉、百花蚀骨）；江湖散传——诸子百家与诗词气（白驹过隙、长风万里）。
4. **后缀写实**：掌/拳/刀/剑/棍/手/式/功/钉/锥。"X法"仅限兵器技艺总称（刀法、棍法）；"诀"仅限心法口诀。禁"术/咒/禁/大法"。
5. **字级红线（仙侠标志字）**：真（真气/真元）、灵、仙、煞、罡、符、咒、御（御剑/御风）不出现在武功名中。词级例外：**经脉、丹田、气血、吐纳、导引**是中医道家养生正统、武侠内功基础设施（金庸全用），叙事与命名均可用；**金丹、元婴、渡劫、飞升、灵气、法力**是仙侠禁词，任何位置不得出现。
6. **绝学 = 门派之魂，不是最大的一招**。每派两条绝学共享一个精神命题（丐帮"天下无丐"、武当"上善若水 × 厚德载物"、唐门"杀人于无声"），品阶最高不是靠数值堆，是靠立意收束。

## 三、节奏型语言（数值后置的代价是先定形状）

ADR-0010 定了"数值后置"。设计稿不写具体数，只写**节奏型**——五种，同时是内容生产的对齐语言：

| 节奏型 | 消耗 | 冷却 | 伤害倾向 | 与出招调制器的关系（§3.11 四调制器） |
|---|---|---|---|---|
| 快频小伤 | 极低 | 极短 | 低 | 重复衰减常触发；内力几乎无感 |
| 均衡 | 低 | 中 | 中 | 四调制器均衡作用 |
| 慢重爆发 | 高 | 长 | 高 | 内力调制敏感（火系易见底）；冷却归零期由其他招补位 |
| 群攻 | 中 | 中 | 单体低/总量高 | 多目标驻守的清理主力 |
| 功能 | 低~中 | 中 | 极低 | 价值在 effects 不在伤害；靠条件/概率触发 |

**门派节奏 = 节奏型的分布**：丐帮池内慢重爆发与快频两极分化（爆发型）；武当均衡与功能型占多（持久型）；唐门功能型（DoT/破防）占比最高（累积型）。这是内容层调参，引擎不感知"节奏"。

## 四、心法的四类效果（primitive 候选集见 `docs/engine-reservations.md` §3）

每派 4 条心法按四类各占其位，全池错开不重样：

| 类 | 机制表达 | 示例（见样稿） |
|---|---|---|
| **常驻数值** | `stat-modifier` 无 duration | 「高枕无忧」（生命回复）、「行云流水」（内力上限） |
| **条件加成** | `stat-modifier` + `condition` | 「千杯不醉」（内力低于阈值时回复加速） |
| **被动触发** | `chance` + trigger + `condition` | 「夜雨埋针」（暴击时追加暗器伤害） |
| **改变机制** | 改造既有机制的参数（与兽的放大器模型同构） | 「万毒淬体」（中毒不可被抵抗衰减） |

**心法是内力上限三大来源之一**（武功等级 + 心法 + 装备词缀，ADR-0010／0019）。每派心法线的内力性格对齐门派：丐帮重回复速度（火系倾泻需要快速回内）、武当重上限与防御（承载）、唐门重消耗转化（金系耗内破防要"值回票价"）。

## 五、兵器与动词池

动词池现状四类：剑 / 刀 / 棍 / 拳掌（motion：thrust 刺、sweep 扫、chop 劈、grapple 拿）。

**唐门需要第五类：暗器**（掷/弹/钉/泼——motion 归属：直线类→thrust，泼洒类→sweep）。加兵器类 = 往 combat-text 词库追加动词条目，**纯内容追加，零引擎改动**（ADR-0011 第 8 条：搭配表是内容不是引擎逻辑）。落地顺序待定：MVP 若词库未备，唐门暗器线延后启用，唐门 MVP 武功先走拳掌（毒掌）+ 刀（毒刀）两线。

**每派双兵器**：丐帮 = 棍 + 拳掌；武当 = 剑 + 拳掌；唐门 = 暗器 + 刀 + 拳掌（毒掌）。拳掌是三派公约数（空手是武人本色），兵器差异塑造画面差异。

## 六、品阶 × 获得 × 文本的三角对齐

| 品阶 | 获得途径（CONTEXT：秘籍掉落 + 贡献兑换） | 战斗文本片段数 | 前置链 |
|---|---|---|---|
| 下乘 | 入门即授 / 贡献低额 | 3 段 | 无 |
| 中乘 | 贡献中额 + 浅层秘籍掉落 | 4 段 | 同脉下乘 |
| 上乘 | 贡献高额 + 深处秘籍掉落 | 5~6 段 | 同脉中乘 + `martialLevelMin` |
| 绝学 | 镇派之宝：贡献高额 + 秘境核心掉落 | 7 段 | 同脉上乘 + 高 `martialLevelMin` |

**前置链沿脉生长**（`prerequisites.martialIds` + `martialLevelMin`），同脉四阶一以贯之（丐帮掌脉：饿虎拦路 → 黑虎偷心 → 醉里乾坤 → 平地惊雷）。跨脉学习无武功前置、只设 `martialLevelMin`——鼓励横向混搭，纵向锁深度。

> ⚠️ **ADR-0019 后的口径**：境界已取消。**造诣是纯显示层，不产生任何门槛**——所有前置一律用 `martialLevelMin`（武功等级下限），原 `realmIndexMin` 字段已废弃。档位名一律取自 50 档表（`docs/research/xkx100-kungfu-combat.md` §5.1），**不得杜撰**。

## 七、流派涌现示例（武功池 × 装备词缀）

系统里没有"流派"的 schema，它只在玩家装配里出现（CONTEXT 流派词条）。武功池要为以下组合预置咬合点：

1. **毒火燎原**：丐帮「天下无丐」（火系全体灼烧）+ 唐门「百花蚀骨」（毒系全体中毒）+ 火/木辅系装备 → 双 DoT 群体流。咬合点：两条都是绝学级群攻，多目标 targetSelector 叠加。
2. **雷霆万钧**：丐帮「平地惊雷」+ 心法「千杯不醉」+ 雷系暴击词缀 → 极限爆发。咬合点：招式 crit-modifier 与心法内力条件的组合窗口。
3. **以柔克刚**：武当「四两拨千斤」（反伤）+ 「厚德载物」+ 土系防御词缀 → 龟反流，省心友好（反伤是被动，不占玩家的指令）。
4. **追风赶月**：江湖「白驹过隙」（提频）+ 「风行草偃」+ 风系词缀 → 高频攻击流，再叠雷系暴击词缀成"高频暴击"变体。咬合点：rate-modifier 与 crit-modifier 正交可叠。

设计新武功时自查：**它至少能进一个上述形态的组合，或开辟一个新形态**——否则不做（内容为构筑服务，不为图鉴凑数）。

## 九、生产自查清单（每批必过）

1. style-guide 禁词表 + 本文 §二命名军规（字级红线逐条扫）；
2. 系别×方式分布：同批新增不得使某派偏离缺省系别超过 ±2 条（风味例外需注明）；
3. 节奏型分布：同批五型皆有，不得全堆"均衡"；
4. 文本变体意象：每招 ≥2 条画面方向，且与兵器动词池自洽（棍招不出现"剑光"意象）；
5. 前置链连通性：每条武功的 prerequisites 指向的武功必须存在于池中（将来由校验器检查，生产期人工保证）。
